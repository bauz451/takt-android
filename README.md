# Takt für Android

Native Android-App für den Takt-Kalender mit exakten Alarmen, Alarmton-Auswahl, Vibration und Sperrbildschirm-Anzeige.

## Test-APK

Unter **Actions → Takt APK bauen → Artifacts** kann die aktuelle Test-APK heruntergeladen werden.

## Sicherheit

In diesem Repository werden keine API-Schlüssel gespeichert. Für dauerhaft updatefähige Release-APKs wird später ein privater Signierschlüssel als GitHub Actions Secret hinterlegt.
